# v0.1.8

- Preserve page margins in Fit Text Width, center the page horizontally, and allow sideways panning. Add Standard, High, and Ultra preview quality settings, with bounded raster memory and background rendering.
- Add independent autosave controls: enable or disable timed saving, choose a delay from 50 ms to 60 seconds, and optionally save when the window loses focus. The default remains 100 ms after the last edit. Live preview reads unsaved edits without writing them to disk.
- Autoclose math delimiters, convert an empty dollar pair to block equation spacing with Space, skip the existing closing delimiter, and remove empty pairs with Backspace. Editing remains compatible with undo and Vim mode.
- Enable editor font ligatures by default with a settings toggle. Make equation backgrounds optional and customizable while preserving syntax colors.
- Keep heading navigation titles readable and show the active light or dark theme in the theme button, with a laptop badge when following the system.

Typst remains pinned to 0.15.1. High and Ultra preview quality use more processing time; Standard remains the default. Existing installations can use **Update available**, then **Restart to update**. Linux package installations update through their package manager.
