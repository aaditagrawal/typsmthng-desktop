# v0.1.10

- Wrap selected text in math delimiters by typing `$`, with a single undo step.
- Paste clipboard images into the editor with Ctrl+V or **Paste image**. The editor saves each image beside the source file and inserts its Typst reference.
- Show file suggestions automatically while entering paths in image, import, include, and data-loading expressions.
- Keep file rows compact, show more of long filenames, and support keyboard navigation through folders.
- Keep diagnostics in one bounded panel. The status bar shows a short message, and the diagnostic count opens or closes the details.
- Reduce work on the editor thread while typing, reuse minimap heading labels, and discover project compile settings in the background.
- Submit verified releases to COPR even when GitHub reuses an existing release candidate.
- Include the dependency maintenance and preview-centering fixes merged since v0.1.9.

Typst remains pinned to 0.15.1. Existing installations can use **Update available**, then **Restart to update**. Linux package installations update through their package manager.
