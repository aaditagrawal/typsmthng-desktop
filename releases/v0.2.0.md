# G(TK)ood things come to those who wait

The GTK desktop release brings typsmthng back to its original visual identity: compact monospace controls, orange accents, a focused project home, and an editor and preview that work together in light and dark themes. It runs natively with GTK 4 and GtkSourceView, without a browser or WebView.

## A faster editing loop

- New edits cancel obsolete compiler processes instead of waiting for them to finish.
- Speaker notes load when presenting, removing a second compilation from ordinary editing.
- Google Font downloads run in the background. Preview starts with available fonts and refreshes when downloads finish; PDF export waits for font preparation.
- Unchanged preview pages reuse their decoded images, even when another page changes.
- Project search runs in the background, with stale results discarded.
- Font caches, compiler detection, lazy file menus, and coalesced filesystem events reduce repeated work.

## A more complete native app

Folder-backed projects, templates, ZIP and LaTeX import, project and PDF export, source diagnostics, search and replace, settings, recent projects and workspaces, and presenter/audience windows are available in the native interface. Presentation includes speaker notes, timers, annotations, slide navigation, and black/white screens.

This release also fixes selected-text deletion, layout updates during window resizing, LaTeX verbatim and graphics paths, file renames across project boundaries, partial project export, and compile-queue handling that could lose newer edits during navigation.

## Downloads and installation

Choose the artifact matching your platform. macOS downloads are **unsigned by a Developer ID and not notarized by Apple**; the bundles use ad-hoc signatures for local integrity. Gatekeeper may require approval in System Settings → Privacy & Security after the first launch attempt. Linux packages and Windows installers include the appropriate runtime/compiler files. `SHA256SUMS` contains the published artifact checksums.

The Windows installer preserves unrelated files during installation, upgrade, and removal. Typst compiler downloads used by the build are pinned and checked against SHA-256 digests.

## Known limits

Typst still performs full document compilation rather than retaining an incremental compiler session. Very large documents, initial native image decoding, and slow disks can still cause delays. A first preview may use fallback fonts until a requested Google Font finishes downloading. Keep backups while the app remains in beta.
