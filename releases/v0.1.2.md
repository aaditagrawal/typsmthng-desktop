# v0.1.2

Updates now follow an explicit click-to-download, click-to-restart flow inspired by T3 Code.

- Added an Update available button to the native header. Updates download only
  after clicking it, with progress shown in place.
- Added Restart to update for AppImage, macOS bundles and Windows installations.
  Documents are saved before the app exits. Normal app closure never installs an
  update.
- Added periodic stable release checks, checksum verification, retry handling,
  and installer failure reporting. Linux package installations continue to use
  their package manager.

Existing v0.1.1 installations need to install v0.1.2 using the existing download/installer flow. Future updates can use the new button.
