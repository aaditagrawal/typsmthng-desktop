# typsmthng 0.1.0

The GTK 4 edition starts a new release history for typsmthng. It uses GTK 4, libadwaita and GtkSourceView 5, with one native header bar, desktop theme accents, and the familiar project, editor, preview, and presentation layouts.

## Included

- Folder-backed projects, workspaces, templates, ZIP and LaTeX import, project export, and PDF export.
- Typst syntax highlighting, diagnostics, search and replace, automatic saving, undo/redo, and Vim-style modal input.
- Background compilation, multi-page SVG previews, zoom, and responsive editor panes.
- Presenter and audience windows, speaker notes, timers, slide navigation, pen/highlighter annotations, laser pointer, and black/white screens.
- Live system appearance, native Adwaita controls and accents, asynchronous file pickers, and adaptive alerts.
- GtkSourceView 5 native Vim input and a visible command bar.

The AppImage bundles its text-rendering libraries and preserves the pinned Typst executable intact. Its presentation test runs in a clean environment without system GTK or Typst.

This release also fixes undo history being cleared after atomic saves, dialog header handling, presentation pointer input, and GTK 4 event handling when preview widgets are replaced.

## Downloads

- Linux x64: AppImage, Debian package, RPM, and Flatpak. AppImage/deb/rpm target Ubuntu 24.04 or compatible systems with glibc 2.39 or newer. Flatpak uses the GNOME 50 runtime.
- macOS Apple Silicon and Intel: DMG installers. Apple Silicon requires macOS 14 or newer; Intel requires macOS 15 or newer.
- Windows x64: installer with the GTK runtime and Typst compiler.

The Typst compiler is pinned to 0.15.1. SHA256SUMS contains checksums for every installer. Linux deb/rpm packages use system GTK libraries; the other distributions bundle the required runtime or declare a Flatpak runtime.

macOS builds use ad-hoc signatures and are not notarized by Apple. Gatekeeper may require approval in System Settings under Privacy & Security.

## Compatibility

GTK 4.12, GtkSourceView 5.4 and libadwaita 1.5 or newer are required for system packages. System accent preferences require libadwaita 1.6 or newer; the Ubuntu 24.04 AppImage runtime uses Adwaita’s default accent.

This is a beta release. Vim input uses GtkSourceView 5 and does not load Vim plugins. Physical multi-monitor placement and compositor-specific fractional scaling may vary by desktop.

The old release series and Git history have been replaced by this 0.1.0 baseline. Existing clones should be cloned again to follow the new history. This version replaces the previous series; it is not an automatic upgrade from higher version numbers.
