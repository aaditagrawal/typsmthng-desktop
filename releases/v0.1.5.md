# v0.1.5

More control over the editor, document preview, and fonts.

- Switch between source, split, and preview views.
- Zoom the editor with Ctrl+scroll and keyboard shortcuts. Zoom the preview at the pointer with Ctrl+scroll, pinch gestures, or presets.
- Fit the preview to the text column by cropping page margins.
- Highlight Typst markup, code, and math, with underlined headings.
- Navigate document headings from a minimap beside the editor.
- Choose installed or Google Fonts families for the interface and editor. Adjust interface size, editor line spacing, and ligatures, or reset to the defaults.
- Resolve Auto page size from the system locale.
- Make keyboard interaction checks wait for application readiness and completed saves.

Typst remains pinned to 0.15.1. Existing installations can use **Update available**, then **Restart to update**. Linux package installations update through their package manager.
