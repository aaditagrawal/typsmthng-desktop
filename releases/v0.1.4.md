# v0.1.4

Sharper document previews at different zoom levels and display scales.

- Render pages at the displayed pixel size and refresh them when zoom or display scale changes.
- Keep scrolling and resizing responsive by rendering visible pages in the background and discarding obsolete work.
- Remove the page-wide source-navigation tooltip. Clicking text and equations still opens their source.
- Speed up CI builds and release publishing with parallel Flatpak builds, compatible caches, and verified package promotion.

Typst remains pinned to 0.15.1. Existing installations can use **Update available**, then **Restart to update**. Linux package installations update through their package manager.
