# typsmthng 0.1.1

Faster live previews, accurate click-to-source navigation, and quieter diagnostics.

## Changelog

- Keep the Typst 0.15.1 compiler, parsed sources, and fonts in memory between edits. Imports and assets are revalidated on each compilation, so changed or newly created dependencies are picked up.
- Click rendered text or a formula once to jump to its source file, line, and column. Local imports, Unicode text, transformed content, zoom, and cropped presentation pages use actual compiler source mappings.
- Wait for 900 ms without typing before displaying diagnostics or compiler errors. Successful previews continue updating independently, with the existing configurable compile delay.
- Discard results from older editor revisions and cancel pending diagnostics when typing resumes. Keep the last successful preview visible while an expression is unfinished.
- Reuse unchanged preview widgets while updating their source mappings, including edits that move source lines without changing the rendered page.
- Refresh the compiler's font store after Google Font downloads complete.

## Performance

On a ten-page text-and-math document with system fonts enabled, the median repeated-edit compilation and SVG-generation time fell from **222.35 ms to 3.66 ms**, about **61 times faster**. The first persistent compile took 134.34 ms. All twelve document versions matched the CLI's SVG output after whitespace normalization.

These are measurements from one Linux device, not a guarantee for every document. They exclude the editor debounce, GTK image decoding, and painting. The implementation uses upstream Typst libraries and the persistent-world approach from typrst; it does not use typrst's experimental independent compiler.

[Benchmark method and reproduction commands](https://github.com/aaditagrawal/typsmthng-desktop/blob/v0.1.1/docs/preview-performance.md)

## Downloads

- Linux x64: AppImage, Debian package, RPM, and Flatpak. AppImage/deb/rpm require Ubuntu 24.04 or a compatible system with glibc 2.39 or newer. Flatpak uses GNOME 50.
- macOS: DMGs for Apple Silicon and Intel. Apple Silicon requires macOS 14 or newer; Intel requires macOS 15 or newer.
- Windows x64: installer with GTK and Typst included.

Typst remains pinned to 0.15.1. PDF export and presentation-note queries retain the existing CLI backend. `SHA256SUMS` includes every installer.

## Validation

75 automated tests passed locally, including the GTK source-navigation and diagnostic-timing test. Clippy, rapid editing and file switching, native keyboard/pointer checks, and release presentation smoke tests also passed. Publication is gated on package verification for all supported platforms.
