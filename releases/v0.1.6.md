# v0.1.6

Writing assistance, document navigation, and more export options.

- Complete Typst code with Ctrl+Space and inspect plain-text hover help. Suggestions use the current unsaved document, project imports, and compiled labels.
- Format the document with Ctrl+Shift+I or the command palette. Formatting keeps import order, Unicode selections, scroll position, and a single undo step.
- Navigate compiled headings, including imported and generated headings. Use Ctrl+Shift+J to reveal the source cursor in the preview.
- See rendered page and non-whitespace character counts, including generated text.
- Export PDF with a chosen PDF profile, all SVG or PNG pages in a ZIP, or experimental HTML. Ctrl+Shift+E remains the quick PDF export shortcut.
- Enable centered scrolling in editor settings, or use the preview toolbar's 2× magnifier. Both controls default off; centered scrolling is saved as a preference.
- Keep preview and export configuration consistent for fonts, package paths and caches, and reproducible timestamps. Permanent local compatibility tests compare against the pinned compiler.
- Separate project imports, note storage, and preview caching from the GTK controller, with documented module interfaces and focused tests.

## Thanks to Typesetter

Thanks to Haydn Trowell and [Typesetter](https://codeberg.org/haydn/typesetter) for the inspiration behind this release's writing and preview quality-of-life improvements: semantic completion and hover help, formatting, heading navigation and statistics, export profiles, centered scrolling, and the preview magnifier. We implemented these ideas independently using the official Typst and Typstyle APIs.

Typst remains pinned to 0.15.1. Existing installations can use **Update available**, then **Restart to update**. Linux package installations update through their package manager.
