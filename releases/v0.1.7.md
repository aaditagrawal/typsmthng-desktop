# v0.1.7

- Render editor previews directly with Typst's glyph rasterizer and draw at device-pixel resolution, including fractional display scales. Live compilation, source navigation, and background page caching continue to work.
- Reduce changed-page rasterization time in the text-and-math benchmark from 22.9 ms to 0.47 ms at 1× and from 34.9 ms to 1.83 ms at 2×. These timings exclude compilation and GTK painting.
- Add Fedora COPR source packaging, an offline Fedora RPM build check, and configurable release publishing to a COPR project. Source RPMs include vendored Rust dependencies and the checksum-verified Typst compiler.

Typst remains pinned to 0.15.1. Fedora COPR publishing requires the repository's `COPR_PROJECT` variable and `COPR_CONFIG` secret. Existing installations can use **Update available**, then **Restart to update**. Linux package installations update through their package manager.
